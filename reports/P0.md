# P0 — физика правила обучения на реальных байтах. Отчёт (2026-09-18)

Данные: отложенные документы OpenOrca-100k (не участвуют в обучении), байты,
потеря только на ответе. Машина: $N=256$, один уровень (кроме L2), жёсткая
сигмоида, $\alpha=0{,}5$, $\gamma_{in}=0{,}25$, $\beta=0{,}2$, 16 хопов
(база). Истина — autograd потери чтения через хопы свободной фазы,
используемый исключительно как измерительный прибор. Полные таблицы:
`runs/p0/summary.md`; сырые строки по шагам: `runs/p0/*.rows.jsonl`;
воспроизведение: `python -m drrem.probes.p0_physics --stage sweep`.

## 1. Что проверялось

Для каждого байта ответа (64 документа × 16 байт × 4 батча = до 64 шагов
измерения на конфигурацию):

- косинус локального обновления $S$ (контраст фаз) и $A$ (клин,
  циркуляция, трассовое STDP) с минус-градиентом по связанным параметрам
  ($\partial C/\partial S_{ij}=G_{ij}+G_{ji}$, $\partial C/\partial a_{ij}=\gamma(G_{ij}-G_{ji})$);
  наклон $\langle\Delta S,-\nabla\rangle/\|\nabla\|^2$ (при точном EqProp равен 1);
- то же по отдельным образцам;
- контроли: перемешанные цели (реальные байты, чужие пары) по батчу и по
  образцу; случайное направление;
- тест снижения потерь без градиента: шаг нормы $r\|S\|$ вдоль правила, вдоль
  истинного градиента и вдоль случайного направления, повторная свободная
  фаза из того же состояния;
- память: относительное расхождение свободного состояния при сброшенном и
  при чужом (переставленном по батчу) перенесённом контексте;
- сходимость: невязка неподвижной точки $|x-(Ws+I)|/|x|$; доля хопов с
  ростом энергии; доля активных и насыщенных единиц; невязка тождества §3.2.

### 2.1. Положительный результат: где фазы сходятся, правила точны

При невязке неподвижной точки $\approx0$ контраст фаз совпадает с
градиентом по $S$ с косинусом 0,93–0,999 и наклоном 0,93–1,0; клин,
циркуляция и трассовое STDP совпадают с градиентом по $A$ так же точно.
Тест без градиента подтверждает: шаг вдоль правила снижает потерю на
98–100 % от снижения вдоль истинного градиента. Точность падает
предсказуемо: с ростом $\beta$ (смещение первого порядка: 0,985 → 0,954 при
$\beta$ 0,05 → 1,0), с ростом веса $A$ ($\gamma=1$: 0,935 — несимметричный
якобиан), при двух уровнях (0,94). Дельта-правило чтения совпадает с
градиентом точно (косинус 1,000).

Два разобранных «подозрительных» факта, оказавшихся свойствами, а не
ошибками:

- Косинусы для $S$ и для $A$ совпадают до третьего знака. Градиент по
  образцу в сошедшемся режиме имеет ранг 1: $u\,s^{0\top}$, и оценка EqProp
  первого порядка имеет ту же правую часть $s^{0\top}$; косинусы
  симметричной и антисимметричной частей тогда равны углу между $u$ и $u'$.
- Наклон без поправки равен 2,0: autograd по свободной матрице даёт
  $G_{ij}$ и $G_{ji}$ раздельно, EqProp оценивает производную по связанному
  параметру, то есть их сумму. Введены связанные градиенты и контраст с
  половинной диагональю; наклон стал 0,98–1,0 (тест
  `test_eqprop_contrast_matches_gradient_when_converged`).

### 2.2. Отрицательный результат: сходимость означает отсутствие памяти

Во всех сошедшихся конфигурациях память равна 0,000: свободное состояние
после 16 хопов не зависит ни от сброшенного, ни от чужого контекста.
Причина — единственность неподвижной точки при $\rho(W)<1$: за такт
состояние становится функцией текущего байта. Контроль с перемешанными
целями по батчу это выдал первым: на первом байте ответа (у всех документов
один входной байт «\n») он равен истинному косинусу 0,993, дальше 0,5
(общая компонента состояний). Многостабильность не спасает: при
$g_S=1{,}2$ ($\rho(W)=1{,}66$, 21 % насыщенных единиц) и 64 хопах состояние
опять сходится к входозависимой точке, память 0,002 — вход выбирает бассейн.

Память появляется только в несошедшемся режиме: H8 — 0,017, H4 — 0,12,
H2 — 0,35, gS=0,8/H4 — 0,22. И там последовательные фазы ломаются:
косинус −0,03 (H4) и −0,09 (H2), контроль с перемешанными целями такой же,
шаг вдоль правила почти не снижает потерю (−0,004 против −0,091).
Механизм: подталкиваемая фаза, стартуя из конца несошедшейся свободной,
продолжает релаксацию; контраст измеряет её, а не отклик на подталкивание.
Это подтверждается тем, что «перемешанный» контраст не отличается от
истинного — обновление не зависит от цели.

### 2.3. Перепроверка отрицательного результата: близнецовые фазы

Если механизм верен, отрицательная фаза той же длины из той же точки
сокращает релаксацию, и точность должна вернуться без сходимости. Так и
вышло: H4 −0,03 → 0,971 (наклон 1,09, память 0,12 сохранена), H2
−0,09 → 0,875 (память 0,35), gS=1,2/H16 0,13 → 0,969 (память 0,09), gS=0,8/H4
0,957 при памяти 0,22, $\gamma=1$/H4 0,947. Тест снижения потерь: −0,090
против −0,091 (H4), −0,320 против −0,322 (gS=1,2). Клин для $A$ столь же
точен (0,97). Траекторные правила для $A$ (циркуляция, STDP) в режиме
«близнецы из начала такта» хуже (0,68–0,70): их разность по длинным
релаксационным траекториям чувствительна к второму порядку; в режиме
«близнецы из конца свободной фазы» они точны (0,94–0,95 при H4). Вывод для
машины: $A$ учить клином по концам фаз; траекторное STDP — только как
физическая реализация того же в режиме продолжения из конца.

Побочный артефакт, найденный по контролю: случайный CNN-фронт давал
косинус перемешанного контроля 0,88 — его выход почти одинаков для всех
окон (общая компонента случайной свёрточной сети). Центрирование выхода при
калибровке вернуло контроль к 0,55, как у вложения байта.

## 3. Что это значит для программы

1. Правило обучения §3.2–3.3 верно количественно, а не качественно, и не
   требует сходимости, если фазы — близнецы. Это снимает конфликт D3 на
   уровне правила: машина может работать в переходном, околокритическом
   режиме, где у неё есть память, и всё равно получать почти точный
   локальный градиент.
2. Память в единственном быстром состоянии есть только память
   «недорелаксации»: утечка без управления. Значит, носитель контекста —
   отдельный объект проектирования: медленные переменные (следы §2.1,
   адаптация) либо намеренно неполная релаксация с близнецами. Это входит в
   P1 как главная ось.
3. Ложные тревоги и настоящие дефекты разделяются только контролями:
   перемешанные цели и случайное направление обязательны в каждой пробе.

### 4.1. Что получилось

- Правило учит: за 50 батчей (≈ 0,7 М байт ответа) все режимы уходят с 8,2 до
  3,85–4,26 бит/байт, ниже униграммы. Близнецовые режимы с памятью
  заметно лучше сошедшегося без памяти (3,85 против 4,26), но биграммный
  предел 3,664 не достигнут ни одним.
- Итеративный вывод виден на отложенной выборке: в twin H4 потеря
  падает по хопам с 4,95 (первый хоп) до 3,85 (четвёртый); в base с 4,74
  до 4,26 за 16 хопов.
- Память в близнецовых режимах после обучения выросла до 0,53–0,67:
  машина сделала свою динамику медленной и стала удерживать контекст.
  В сошедшемся режиме память осталась 0,000 и после обучения — вывод §2.2
  подтверждён в замкнутом цикле.

### 4.2. Отрицательный результат и его разбор

После 50–100 батчей все режимы ухудшаются (base 4,26 → 4,61; twin H4
3,85 → 4,04). Это не переобучение: потеря на обучении растёт вместе с
отложенной (base: скользящее среднее 4,14 на шаге 26, 4,63 на шаге 300).
Диагноз по нормам и спектру:

- $\|A\|_F$ растёт линейно и без предела (twin H4: 4,5 → 17 → 32 → 45 → 56 →
  66 → 77), $\|S\|_F$ 4,5 → 36, $\lambda_{\max}(S)$ 0,55 → 12,5, $\rho(W)$ 0,54 → 10,8;
- доля насыщенных единиц растёт до 0,42–0,68: насыщенная единица
  постоянна, не несёт информации и не пропускает подталкивание ($\rho'=0$);
- вместе с ростом $\rho(W)$ падает выравнивание: cos S 0,97 → 0,69 (twin H4),
  невязка неподвижной точки 0,11 → 0,30.

Причина — разгон весов: 256 обновлений на батч с шагом 0,01 и без
восстанавливающей силы; клин для $A$ по построению вдвое крупнее
связанного градиента при $\gamma=0{,}25$, и у потери нет члена, ограничивающего
$\|A\|$. Правило само по себе верно (косинус остаётся положительным и
высоким), неверна динамика обучения без контроля нормы — ровно дыра D8
программы.

## 5. Итог P0

Пройдена. Правило обучения (контраст фаз → $S$, клин → $A$, дельта → $E_r$)
совпадает с градиентом количественно и без backprop доводит машину с 8,2 до
3,72 бит/байт на реальном тексте за 4,3 М байт ответа. Три факта, которые
меняют программу:

1. Фазы должны быть близнецами (FF-структура в чистом виде), тогда
   сходимость не нужна, и машина может жить в режиме с памятью.
2. Память в одном быстром состоянии — только недорелаксация; носитель
   контекста нужно проектировать отдельно (следы, адаптация, иерархия
   тактов).
3. Контроль нормы и гомеостаз порогов — не гигиена, а условие обучаемости:
   насыщение убивает и ёмкость, и подталкивание.
