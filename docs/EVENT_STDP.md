# Событийное обучение S/A-машины

**Историческая серия с выходами всех уровней.** Текущий режим, изменения сигнала
и единственный последний декодер описаны в [LAST_DECODER.md](LAST_DECODER.md).

Исполняемый событийный режим: [spiking_rrem.py](../drrem/spiking_rrem.py),
[временное ядро](../drrem/core/event_stdp.py). Старые непрерывные модели и их
checkpoint не переименованы в STDP. Исходный диалог README сохранён.

«Полный STDP» здесь означает **полную выбранную pair-based модель**: оба
экспоненциальных плеча, все пары событий, отдельный след каждого ребра,
документа и канала задержки. Это не воспроизведение всех видов биологической
пластичности и не обещание точного полного градиента языковой ошибки.

## Свободная машина

Каждый уровень содержит N нейронов, связанных со своим и соседними уровнями
в обоих направлениях. Для каждого канала задержки есть полные S и A:
`W=S+A`, `S=S.T`, `A=-A.T`. Автосинапсы исключены, факторизации матриц нет.

Байт даёт входное событие в начале своих внутренних тактов. Нейрон интегрирует
задержанные спайки, тонический ток и утечку. Пересечение порога вызывает
бинарный спайк, вычитание порога из потенциала, рефрактерность и прибавку
адаптации. Адаптация повышает следующий порог. Во время рефрактерности
потенциал продолжает интегрироваться, но спайк запрещён: выбран дискретный
вариант с мягким сбросом.

Словарь получает **только фильтрованные спайки**, без прямого доступа к байту
или мембранному потенциалу. Attention, Q/K/V и скрытого трансформера нет.
Это плотная рекуррентная спайковая сеть. Словарь общий для уровней; для разных
горизонтов есть разные выходные таблицы. В связанном режиме таблица первого
горизонта одновременно служит входным кодом. Учитывается производная нормировки
входных строк; входная STDP-поправка и выходная softmax-поправка суммируются.

## Полный временной след

Ядро из README реализовано непосредственно:

\[
K(\Delta t)=
\begin{cases}
A_+e^{-\Delta t/\tau_+},&\Delta t>0,\\
-A_-e^{\Delta t/\tau_-},&\Delta t<0,\\
0,&\Delta t=0.
\end{cases}
\]

Суммируются все пары. Eligibility затухает от момента второго события пары,
а не границы байта. Одновременные события должны составлять один bin;
повторный вызов с нулевым интервалом отклоняется, чтобы не создавать ложное K(0).

Канал с индексом очереди d доставляет спайк через `d-1/2` микротакта.
Приход происходит через полтакта после прошлого постсинаптического события,
новое постсинаптическое событие — ещё через полтакта. Для приходов a и
постсинаптических событий r точная формула шага:

\[
P'=e^{-1/\tau_+}P+e^{-1/(2\tau_+)}a,\qquad
Q'=e^{-1/\tau_-}Q+r,
\]
\[
e'=e^{-1/\tau_e}e+A_+r\otimes P'
-A_-e^{-\frac12(1/\tau_-+1/\tau_e)}Q\otimes a.
\]

Форма e: `(batch, delays, post, pre)`. Следы переносятся между байтами,
сбрасываются при новом документе. Padding не продвигает время и не изменяет
состояние. Сигнал документа соединяется с его следом до усреднения батча.
Экспоненты не обрезаются списком последних пар. CUDA объединяет операции
без изменения формулы; CPU сохраняет независимую простую реализацию.

## Сигнал обучения и обычный Adam

Первый режим `learning=modulated` умножает полный событийный след на ошибку
словаря. Он оставлен как отрицательный контроль: на первом языковом пилоте
второй уровень постепенно замолкал и проиграл замороженным связям.

Основной исследуемый режим `learning=resume` использует принцип
[ReSuMe: STDP желаемых спайков минус STDP фактических](https://pubmed.ncbi.nlm.nih.gov/19842989/).
**Построение желаемого потока для языковой ошибки — наша адаптация принципа,
а не буквальное воспроизведение опубликованного алгоритма целиком.**

Общий словарь выдаёт прогноз на каждом уровне. Отрицательная производная CE
по фильтрованным спайкам вычисляется точно: `E.T @ (one_hot(y)-p)` с явными
коэффициентами усреднения. Это ток отдельной обучающей копии постсинаптических
нейронов. У неё собственные мембраны, адаптация и рефрактерность, но **те же
свободные пресинаптические приходы**, что у основной сети. Цель не подмешивается
в свободный потенциал, историю или считываемый код. На инференсе учителя нет.

Направление обновления: `(e(pre, desired)-e(pre, actual))/teacher_gain`.
Оба потока спайков бинарны. Их разность -1/0/+1 применяется только к
пластичности. Линейность STDP по постсинаптическому потоку позволяет точно
хранить `e(pre, desired-actual)` вместо двух тензоров. Это сохраняет оба
плеча и все пары, экономит память и устраняет вычитание больших близких
следов. Равенство проверяется против двух независимых полных процессов.

Направление разбивается на симметричную и антисимметричную части. Веса меняет
обычный **torch.optim.Adam**, без самописной нормировки шага, BB или
восстановления нормы. Его полноразмерные состояния помещаются в память;
искусственное разделение на отдельные Adam каждого уровня не требуется.
Обучающие сигналы при этом приходят ко всем уровням локально.

Это не CD-k, не отрицательные предложения и не разность энергий двух
незавершённых релаксаций. Однако STDP-направление не объявляется полным
градиентом CE через рекуррентную историю. Обычный Adam не исправляет
ошибочный источник сигнала автоматически; пользу нужно измерять.

## Проверки

[Тесты](../tests/test_event_stdp.py): явная сумма всех временных пар, знаки,
затухание, K(0), задержки, padding, рефрактерность, readout-производная,
нормировка входа, независимость свободного состояния от учителя, необходимость
STDP для обновления S/A, точное восстановление Adam, неизменность машины при
оценке/генерации, равенство одного разностного следа двум полным.

Задача порядка: в каждой паре одинаковые количества всех символов и общий
последний cue; различается порядок A/B, между ними и ответом есть помехи.
На 512 новых последовательностях, отсутствовавших в обучении:

| Режим | Точность последнего уровня | Бит на ответ |
|---|---:|---:|
| Связи заморожены, словарь учится | 61,91% | 0,9395 |
| STDP связей и обучаемый словарь | 94,14% | 0,2400 |
| Учатся только S/A, вход и словарь фиксированы | 84,77% | 0,5094 |
| Начальная машина с тем же фиксированным словарём | 51,95% | 1,0102 |

Сброс истории перед каждым символом даёт 50%. Это свидетельство обучаемого
временного кода, **не тест понимания языка**.
[План и сырые результаты](../reports/event_stdp_20260923/order_final).

Языковые прогоны, отрицательные пилоты и исходники каждого запуска:
[event_stdp_20260923](../reports/event_stdp_20260923). Вход фиксирован в чистом
сравнении обучения S/A; связанный вариант проверяется отдельно. Признаки
сравниваются независимыми одинаковыми заново обученными пробниками.
Тест запирает checkpoint до чтения test; штатное продолжение после него
запрещено. Разделение документов новое для серии, но сам корпус исторически
переиспользовался: абсолютная историческая неприкосновенность не заявляется.

Числа и кривые собраны в [отчёте](../reports/event_stdp_20260923/REPORT_RU.md).
В чистом сравнении на 256 отложенных документах: STDP 4,3209 против 4,6552
у замороженных S/A; униграмма 4,6643, биграмма с тем же бюджетом ответов 3,5975.
Выигрыш последнего уровня подтверждён, но первый штатный выход ухудшился
на 0,0317 бита. Независимые пробники обоих уровней улучшились; это разные
утверждения, их нельзя подменять друг другом. Свободная генерация пока бессмысленна.

Для общего входного/выходного словаря устранён измеренный перекос масштаба:
при `input_credit=.1` входной сигнал превосходил выходной примерно в 38 раз.
`input_credit=.001` выбран по train-измерению и сохраняет оба источника.
Нормы и угол сигналов записываются каждый шаг. Это эмпирическая калибровка
для данной конфигурации, а не доказательство точного суммарного градиента.

В полном связанном режиме на ещё 192 заранее зарезервированных документах:
h1 4,6752 против 4,7916 при замороженных S/A; униграмма 4,7836.
Однако среднее восьми горизонтов 4,7294 практически равно униграмме 4,7285;
его выигрыш над контролем статистически не подтверждён. Нельзя объявлять
этот результат решением задачи плотной семантики. Биграмма на том же наборе
даёт 3,7217. Планы, интервалы и примеры генерации находятся в отчёте.

Цена полного режима на GB10: медиана 1,55 с на батч (около 594 целевых
байтов/с), около 198 MiB пикового выделения CUDA в обычном шаге; состояния
полноразмерного Adam занимают 20 MiB. Экономия памяти получена точным
объединением вычислений, без факторизации ребёр или удаления плеч STDP.

## Оставшиеся расхождения и допущения

1. S/A здесь не доказывает убывание исходной Hopfield-энергии; само разложение
   является перепараметризацией W. Для общей энергии неверно, что любая
   кососимметричная A движет состояние по её изолиниям. Локальная цель
   событийного учителя — предсказательная CE.
2. Учитель и STDP не дают доказанного полного рекуррентного градиента.
   Поздние колебания языковой ошибки нельзя прятать выбором лучшего шага.
3. Мембрана и спайк разделены, но отдельного ассоциативного content-поля
   с собственной доказанной энергетической динамикой пока нет.
4. Постоянные времени и сетка задержек задаются конфигурацией. Обучаются веса
   каждого канала, не непрерывные задержки или все параметры нейрона.
   При 8 микротактах на байт `tau_eligibility=64` — 8 байтов как e-folding
   scale, не гарантия памяти абзацев. Жёсткого обрезания следа нет, но масштабы
   выбранного режима коротки.
5. Сверхсходимость, плотная семантика и качество свободных ответов не следуют
   из названия STDP или успеха на задаче порядка. Языковой бюджет невелик.
6. Checkpoint тренера сохраняется на границе батча. Полного возобновления
   посреди живого документа пока нет; отдельно временное ядро сохраняет
   все свои следы. Веса имеют оба знака; закон Дейла не навязан.

Маршрутная цена, экономия hops и adaptive halting сейчас не оптимизируются.

## Запуск

Связанный входной/выходной код и событийное обучение всех уровней и входа:

```bash
python main.py train --out reports/my_stdp \
  --N 256 --prompt 64 --response 64 --steps 360 \
  --learning resume --core-lr .0001 --tied --learn-input --input-credit .001
```

Чистое сравнение S/A: добавить `--no-tied --no-learn-input`, парному контролю добавить
`--frozen`. Данные, seed и бюджет должны совпадать. `--final-test` использовать
после окончательного выбора. `--resume` требует прежнего протокола,
конфигурации и хешей исходников.

```bash
python main.py sample reports/my_stdp/checkpoint.pt \
  --prompt 'The capital of France is' --bytes 128
python -m tests.run_all
```

Те же команды доступны как `python -m scripts.train_spiking_stdp` и
`python -m scripts.sample_spiking_stdp`. Режим вызывается явно; ранее пустой
`main.py` теперь предоставляет этот вход. Старый CLI непрерывной машины не переключается
на новые спайки или новое обучение незаметно для пользователя.
