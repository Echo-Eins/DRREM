# Проверяемое энергетическое обучение RREM

Реализация: `drrem/rrem_repaired.py`, `drrem/core/predictive_energy.py`.
Тренер с официальными Adam/Muon и без двухфазного контраста описан отдельно:
[локальные и глобальные производные](OFFICIAL_OPTIMIZERS.md). Ниже описан
предыдущий двухфазный алгоритм, сохранённый для воспроизводимого контроля.
Замысел и требования остаются в диалоге [README](../README.md), особенно §11,
§14–15. Предыдущий аудит сохранён в `reports/repaired_audit_20260919/`.

Главное исправление: ошибка верхнего уровня теперь возвращается по исходящим
связям в состояния нижних уровней. На каждом уровне есть предсказательная энергия
и привязка к общему словарю. Пассивный след пресинаптической активности сам по себе
этого не обеспечивал: он считал сообщения соседей константами, а единственная
читалка на последнем уровне оставляла внутренние связи первого без сигнала.

## Энергия и перенос ошибки

Для одного наблюдаемого байта фиксируются причинный контекст, временные следы,
задержки и условные коэффициенты маршрутизации. Пусть

\[
 W_m=(S_m+\gamma_A A_m)\odot g,\qquad
 q_{ri}=\sigma(b_{ri}+c_{ri}\,\mathrm{context}_i-\theta_i-\beta_a a_i-\beta_{ref}ref_i).
\]

Маршрут на ребре: \(g_{ij}\frac1R\sum_r q_{ri}q_{rj}\). По умолчанию \(R=2\).
Сумма двух произведений допускает матрицу ранга 2 и уже не сводится к одному
перемасштабированию на нейрон. Произвольную матрицу маршрутов такая форма не
представляет. Промежуточный тензор `(batch,D,D)` не создаётся: используются
матричные умножения и `(batch,rank,D)` коэффициенты.

\[
 f(z)=I+\frac1R\sum_r q_r\odot
    \left[W_0(z\odot q_r)+\sum_{m>0}W_m(h_m\odot q_r)\right],\quad
 \widehat z=\tanh f(z),\quad e=z-\widehat z.
\]

Энергия уровня и полная энергия:

\[
 F_\ell^\beta=\tfrac12\|e_\ell\|^2+
 \tfrac{\lambda_s}{2}\|z_\ell\|^2+
 \beta\,\mathrm{CE}_\ell(z_\ell,Y),\qquad
 F^\beta=\sum_\ell F_\ell^\beta.
\]

CE усредняется по существующим горизонтам данного документа. Паддинг и цели за
границей ответа не участвуют. Во всех уровнях по умолчанию один словарь `E` с
восемью таблицами прогнозов; вход действительно связан с таблицей горизонта 1.
Второе состояние нейрона управляет коммуникацией, не подменяя знаковое содержание.

При \(\delta=e\odot(1-\widehat z^2)\):

\[
 \nabla_z F^\beta=e+\lambda_s z-
 \frac1R\sum_r q_r\odot W_0^T(\delta\odot q_r)
 +\beta\nabla_z\mathrm{CE}.
\]

Именно член с \(W_0^T\delta\) возвращает ошибку соседям. Он вычисляется для всех
уровней одновременно. Короткая релаксация уменьшает эту же энергию; обратный
поиск шага принимает решение отдельно для каждого документа. Гарантируется
невозрастание **суммы** энергий при фиксированном контексте. Отдельные слагаемые
могут расти, пока другие убывают; ошибка предсказания без учителя тоже не обязана
монотонно уменьшаться на каждом хопе.

## Обучение без ленты последовательности

1. Свободная фаза: `hops` шагов с \(\beta=0\), без доступа к ответу.
2. Из одного свободного состояния запускаются две независимые короткие фазы
   с \(+\beta\) и \(-\beta\). По умолчанию по 3 шага, \(\beta=0.2\).
3. Обновление строится из разности **частных** производных энергии в конечных
   состояниях: \(-[\partial_p F^{+\beta}-\partial_p F^{-\beta}]/(2\beta)\).
4. На следующий байт переносится только свободное состояние. Параметры меняются
   на границе батча; evaluation и generation их не меняют.

Частные производные и производная по состоянию сверены с автоградом. Конечный
контраст при трёх шагах не объявляется точным градиентом равновесия или BPTT.
История состояний здесь — фиксированная причинная граница локальной задачи;
полное присвоение заслуг через произвольную историю не вычисляется.

Для экономии две фазы исполняются одним GPU-батчем. На общих временных каналах
разность ошибок берётся **до** большого внешнего произведения. Тест проверяет
равенство исходной двухфазной формуле. Память состояний не растёт с длиной
пройденного текста; градиентная лента и обучение через autograd отсутствуют.
Матрицы связей пока плотные, поэтому арифметическая стоимость по ширине остаётся
квадратичной. Мягкие вентили сами по себе не дают аппаратной разреженности.

Цена открытого маршрута теперь явно дифференцируется по `gate` и параметрам
условной маршрутизации. Она добавляется отдельно от контраста: постоянный для
обеих фаз штраф иначе сократился бы. `lam_edge=0.05` проверяется в полном прогоне;
это цена нормированной доли мягко открытых рёбер, а не измеренные GPU-операции.

## Изменения относительно буквальных формул диалога

Это энергия ошибки предсказания, а не \(-z^T S z/2\). В ней и S, и A участвуют
в прогнозе и в энергии. Симметрия S и антисимметрия A сохраняются проекцией,
но этим не доказываются роли «семантика» и «причинность». Такой выбор позволяет
однозначно связать динамику, обучение и измеряемую энергию. Необусловленный
хеббовский член, не соответствовавший динамике, удалён.

Прежнее правило доступно как `learning_rule=local` для абляций. У него исправлены
привязка словаря, знак адаптации и перенос eligibility через маску документа;
его след не называется полным e-prop. Несогласованные старые варианты вентиля,
фазы и энергии запрещены в конфигурации. Фаза в энергетическом режиме, если
включена, задаёт положительную фиксированную подвижность, а не обученную задержку.

Адаптивная остановка, исполнение разреженного fanout, BPE и доказательство
долговременной семантической памяти этой реализацией пока не установлены.

## Воспроизводимый запуск

Из корня репозитория, в окружении с torch, numpy и pyarrow:

```bash
python -m drrem.rrem_repaired --steps 360 --batch 16 \
  --prompt-max 64 --resp-max 64 --eval-every 60 --eval-batches 8 \
  --out runs/energy --name main --set lam_edge=0.05
```

Все прочие параметры, включая `256×2`, 8 хопов, 8 горизонтов, Adam и обе фазы,
явно записываются в журнал и checkpoint. Чтобы продолжить, повторить параметры,
увеличить `--steps` до требуемого общего числа и добавить `--resume .../main.pt`.
Несовпадение файла данных, разделения, размеров обрезки, батча или seed отклоняется.

По умолчанию из parquet заранее выделены 256 dev и 256 test документов. Их ID,
исходные ID, контрольная сумма корпуса и точные ID измеряемого dev сохраняются.
Проверяются пересечения ID и полные копии документов. Указанный `--prompt-max`
действительно передаётся загрузчику. Частоты для начальных смещений берутся только
из обучающих ответов; униграммный контроль печатается отдельно.

`--final-test` запускает заключительную оценку зарезервированной выборки. Этот
флаг добавляется после выбора конфигурации на dev; повторное обучение такого
же запуска после финального test запрещено. Резервирование относится к новой
серии с новой инициализацией: историческую неприкосновенность этого корпуса
во всех предыдущих экспериментах оно не гарантирует.

Checkpoint версии 1 нельзя незаметно исполнить с новой динамикой. Для старых
весов сохранён исходник в `reports/repaired_audit_20260919/source_snapshot.py`.
Новые checkpoints содержат Adam, состояние signal/Muon, BB, счётчики и протокол
данных. Запись атомарная на границе батча.

Проверки: `python -m tests.run_all`. Парный опыт с одинаковыми входом, словарём,
маршрутизацией, документами и различием только в пластичности S/A:

```bash
python -m scripts.compare_predictive_energy --out reports/my_pair --steps 120
```

Числа новой серии, финальное сравнение и ограничения измерений:
[отчёт](../reports/predictive_energy_20260920/RESULTS.md).

Использованные ориентиры: [predictive coding на произвольных графах](https://pmc.ncbi.nlm.nih.gov/articles/PMC7614467/)
и [условия совпадения predictive coding с backpropagation](https://arxiv.org/abs/2103.03725).
Их утверждения о сходимости или эквивалентности не переносятся автоматически
на используемые здесь конечные фазы.
